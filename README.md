# 🏁 Taller2_Carreras

Simulación de una carrera de personajes usando JavaFX y programación con hilos.

## 🚀 Tecnologías
- Java
- JavaFX
- Threads

## 🎮 Funcionalidad
Tres personajes (Messi, Cristiano y Yamal) corren de forma aleatoria hasta la meta.  
El sistema determina automáticamente un único ganador.

## 📁 Estructura
- `Aplicacion.java` → Interfaz y lógica principal
- `HiloPersonaje.java` → Movimiento con hilos
- `Launcher.java` → Ejecución del programa
- `resources/` → Imágenes del proyecto

## 🏆 Resultado
Simulación visual de carrera con detección de ganador en tiempo real.
